# Project background

GENUMAP is a new 2026 study inspired by a Summer 2024 Biostatistics REU project
on UMAP and human genetic variation. The original work asked an important
question but did not produce an independently reproducible analysis. Its scripts
depended on an interactive R session, undocumented local data, and missing
parameters and outputs.

This repository does not attempt to reproduce or repair those analyses. The old
scripts were removed from the active tree and remain available in Git history at
commit `a4bf439`. They are historical context, not part of the GENUMAP method or
evidence base.

The only idea carried forward is the motivating objective:

> Evaluate how UMAP represents human genetic diversity, and determine how much
> apparent structure depends on preprocessing, algorithm parameters, and random
> initialization.

Everything else—the dataset definition, software, experiment design, metrics,
figures, and interpretation—is new work. GENUMAP must therefore be described as
an unofficial, independent study rather than a continuation or release of the
original institutions or investigators.
